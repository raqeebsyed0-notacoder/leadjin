# LEADJIN: The Self-Reliant Intelligence Engine
## System Specification & Manifesto

LEADJIN is a world-class, autonomous intelligence engine designed to transform raw market data into high-value strategic partnerships. It is built on the philosophy of "Total Sovereignty"—an all-in-one ecosystem that handles the entire lifecycle of a lead without external dependencies.

---

### 🏛 The 6 Pillars of Sovereignty

1. **Intelligence Harvesting (The Brain)**
   - Powered by **Gemini 3.1 Pro** and **2.5 Flash**.
   - Real-time enrichment of leads using deep-web intelligence.
   - Automated "Pain Signal" detection to identify high-intent prospects.

2. **CRM Lead Pipeline (The Heart)**
   - A standardized, high-performance SQLite database.
   - Real-time synchronization between AI harvesting and sales operations.
   - Status tracking from "Harvested" to "Closed-Won".

3. **Automated Outreach (The Voice)**
   - Integrated SMTP infrastructure for personalized cold outreach.
   - Intelligent email queuing system to ensure high deliverability.
   - Automated follow-up sequences based on lead engagement.

4. **Strategic Analytics (The Vision)**
   - Real-time data visualization using Recharts.
   - Conversion funnel tracking and ROI analysis.
   - Industry-specific heatmaps (e.g., Saudi Vision 2030 Case Study).

5. **Financial Infrastructure (The Fuel)**
   - Manual invoice and quotation generation.
   - Subscription management for recurring intelligence services.
   - Real-time revenue tracking within the dashboard.

6. **Calendar Synchronization (The Handshake)**
   - Google Calendar API integration for seamless meeting scheduling.
   - Automated "Meeting Ready" triggers when a lead reaches a high score.
   - Availability management to prevent scheduling conflicts.

---

### 🛠 Technical Architecture

- **Frontend**: React 19 + Vite.
- **Styling**: Tailwind CSS 4.0 (utilizing modern variables and high-contrast editorial design).
- **Animations**: Framer Motion (Motion.js) for "Vantablack" fluid transitions.
- **Backend**: Node.js + Express (TSX Runtime).
- **Database**: Better-SQLite3 (Persistent, local, high-speed).
- **AI SDK**: `@google/genai` (Direct integration with Gemini 3 series).
- **PDF Engine**: `html2canvas` + `jsPDF` with custom theme-aware rendering logic.

---

### 🎨 Design Philosophy: "The Technical Editorial"
LEADJIN is designed to feel like a high-end scientific instrument combined with a luxury fashion magazine.
- **Typography**: Inter (Sans) for utility, Playfair Display (Serif) for impact.
- **Color Space**: High-contrast monochromatic (Pure Black/White) with a signature **LEADJIN Blue** (#3182ce) for interactive elements.
- **Interaction**: Micro-interactions on every button, standardized circular controls, and topographic wave backgrounds that react to the system state.

### 🚀 Deployment & Configuration

#### Environment Variables (.env)
Required for full system functionality:
- `GEMINI_API_KEY`: The core intelligence driver.
- `SMTP_HOST/USER/PASS`: For automated outreach.
- `GOOGLE_CALENDAR_ID`: For meeting synchronization.

#### Database Initialization
The system automatically seeds a **Saudi Vision 2030 Case Study** on first boot, providing a pre-configured environment with high-value leads from NEOM, Aramco, and PIF to demonstrate the engine's power.
